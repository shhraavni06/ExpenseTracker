# Expense Tracker System

## Project Description
The Expense Tracker System is a web-based application that helps users manage and track their daily expenses. Users can securely register, log in, add expenses, update or delete records, and monitor their spending through a dashboard.

## Features
- User Registration and Login
- Secure Authentication
- Add, Edit and Delete Expenses
- Search Expenses
- Filter Expenses by Category and Date
- Dashboard with Expense Summaries
- Profile Management
- MongoDB Database Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## Installation

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:

```bash
npm install
```

## Running the Application

Start the server:

```bash
node server.js
```

Open the application in your browser:

```text
http://localhost:5000
```

## Database
MongoDB Atlas is used to store user accounts and expense records.

## Project Outcome
The application provides a simple and convenient way for users to record, organize and monitor their expenses.
